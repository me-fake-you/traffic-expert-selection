## 从哪里看

- [研究内容与证据对应表](RESEARCH_MAP.md)：字段用途隔离与捷径风险、专家证据、融合、预算调度、跨条件测试、只读建议与人工反馈、后续增益和前缀实验。
- [实验索引](EXPERIMENT_INDEX.csv)：按历史实验目录定位结果。目录数、文件数不是独立实验或有效重复的数量。
- [复现说明](REPRODUCING.md)：先运行离线合成示例和测试；真实训练与评价需要另外取得合法数据、对应模型和完整分组条件。
- [发布范围](RELEASE_SCOPE.md)：哪些内容发布，哪些因隐私、许可或缺少运行输入而没有打包。
- [本次验证](VALIDATION.md)：只记录实际运行过的检查，不把历史报告中的通过数当成本次测试结果。

没有只挑正结果：保留完整融合不优于简单方法、学习选择未带来稳定收益、低支持率、外部失败、API 超时和未完成的人审协议。原文引用的他人指标仍是引用，不是本地复现。

## 离线示例

在独立的 Python 3.11+ 环境中，进入 `thesis` 目录：

```sh
python -m pip install -e ".[dev]"
python -m mad_etd.cli demo --output runs/synthetic_demo_001
python scripts/verify_release.py
python -m pytest tests -q
```

示例仅使用两条明确构造的测试记录和规则专家，不调用大模型、不上传数据、不下载流量、不重训论文模型。已有输出目录不会被覆盖。历史实验脚本不是已经迁移完毕的一键全流程系统，具体依赖见复现说明。
